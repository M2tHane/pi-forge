## 1. 概述

一个给 3～20 人小团队用的待办清单。成员登录后能看到团队的全部任务、新建任务、把自己负责的任务标为完成。
成功的标准：新成员不看说明，5 分钟内能完成登录、新建一条任务、把它标为完成。

## 2. 用户与角色

| 角色 | 能做 | 不能做 |
|---|---|---|
| 成员 | 查看全部任务；新建任务；完成或删除自己创建的任务 | 删除别人创建的任务；管理成员 |
| 管理员 | 成员能做的全部；删除任何任务 | —— |
| 未登录访客 | 只能打开登录页 | 查看任何任务 |

账号由管理员在数据库里预置，这次不做注册。

## 3. 需求

### 3.1 登录  REQ-001

用户用邮箱和密码登录，登录后进入任务列表。登录状态保持 7 天。

- AC1 Given 已有账号 alice@example.com / secret123 When 在登录页输入正确的邮箱和密码并点「登录」 Then 进入任务列表页，右上角显示用户名
- AC2 Given 已有账号 When 输入错误的密码并点「登录」 Then 停留在登录页，表单上方提示「邮箱或密码错误」，密码框清空
- AC3 Given 邮箱或密码为空 When 点「登录」 Then 不发请求，空的输入框下方提示「必填」
- AC4 Given 未登录 When 直接打开任务列表页 Then 跳转到登录页

### 3.2 任务列表  REQ-002

列出团队的全部任务，未完成的在前，同一组内按创建时间倒序。每页 20 条。可以按「全部 / 未完成 / 已完成」筛选。

- AC1 Given 团队有 3 条未完成、2 条已完成的任务 When 打开任务列表 Then 显示 5 条，未完成的 3 条排在前面
- AC2 Given 团队有 25 条任务 When 打开任务列表 Then 第一页显示 20 条，底部显示「第 1 / 2 页」，点「下一页」显示剩下 5 条
- AC3 Given 有已完成和未完成的任务 When 选择筛选「已完成」 Then 只显示已完成的任务，网址带上 ?status=done，刷新后筛选仍然生效
- AC4 Given 团队还没有任何任务 When 打开任务列表 Then 显示空状态「还没有任务，新建第一条吧」和「新建任务」按钮

### 3.3 新建任务  REQ-003

在列表页顶部的输入框写标题、可选填负责人，回车或点「添加」新建。新任务出现在列表最前面，创建者是当前用户。

- AC1 Given 已登录 When 输入标题「准备周会材料」并点「添加」 Then 列表最前面出现这条任务，状态为未完成，输入框清空
- AC2 Given 已登录 When 标题为空或全是空格时点「添加」 Then 不新建，输入框下方提示「标题不能为空」
- AC3 Given 已登录 When 输入 101 个字的标题 Then 输入框最多只能输入 100 个字
- AC4 Given 已登录 When 选择负责人「bob」并新建 Then 这条任务的负责人一栏显示 bob

### 3.4 完成与删除任务  REQ-004

每条任务前有勾选框，勾上即完成，再点一次恢复为未完成。创建者和管理员可以删除任务，删除前要确认。

- AC1 Given 一条未完成的任务 When 勾选它前面的勾选框 Then 这条任务显示删除线并移到已完成一组，刷新后仍是已完成
- AC2 Given 一条已完成的任务 When 取消勾选 Then 恢复为未完成并回到未完成一组
- AC3 Given 当前用户是任务的创建者 When 点「删除」并在确认框里点「确定」 Then 任务从列表消失
- AC4 Given 当前用户是成员且不是任务的创建者 When 查看这条任务 Then 不显示「删除」按钮；直接调用删除接口时返回 403，页面提示「没有权限删除这条任务」

## 6. 约束

- 浏览器：最新版 Chrome、Edge、Safari；宽度 360px 以上都能正常使用。
- 数据量：单个团队不超过 5000 条任务；列表页打开时间不超过 1 秒。
- 密码只存哈希；所有接口除登录外都要求已登录。
- 技术栈不限，由架构师决定。

## 7. 通用约定

- 文本字段去掉首尾空格后再校验；任务标题 1～100 个字，负责人取自团队成员。
- 时间：接口里用 ISO 8601（UTC），页面上显示为本地时间「YYYY-MM-DD HH:mm」。
- 列表接口统一分页：参数 page（从 1 开始）、page_size（默认 20，最大 100）；返回 items 与 total。
- 错误返回统一为 { "code": "<英文错误码>", "message": "<给用户看的中文提示>" }；页面直接显示 message。
- 未登录返回 401，页面跳转到登录页；没有权限返回 403，页面显示「没有权限」的提示，不跳转。
- 每个页面都要有四种状态：加载中（骨架或转圈）、空（说明加一个下一步按钮）、出错（提示加「重试」）、无权限（提示加「返回」）。

## 8. 不做的

- 注册、找回密码、修改个人资料。
- 多团队、任务分组、标签、截止日期提醒。
- 移动端 App（只做网页）。

## 9. 待定

- 登录失败多少次后锁定账号：暂不锁定，第二期再定。
- 已完成的任务是否定期归档：暂不归档。
