# 让 agent 停下来的检查：清点（10-14）

每条检查都标了依据：
- **事故**：真实运行里发生过它要防的事（写明出处）。
- **用户决定**：你明确要求过的设计。
- **程序**：引擎自身正确需要的（例如租约、token），agent 正常工作时碰不到。
- **说不出**：找不到事故记录。
- **反例**：真实运行里这条检查让 agent 返工或浪费了时间。

出处缩写：
- **记账**：10-14 的 ledger 实验（`~/pi-forge-runs/ledger/run-01`）。
- **M9**：10-10、10-11 的看板实验。
- **对话**：你在历史对话里提到的问题。

"建议"一列：**删**＝说不出依据，按原则删；**留**；**改**＝留下但放宽。用户 10-14 批准全部按建议办，已实施。
